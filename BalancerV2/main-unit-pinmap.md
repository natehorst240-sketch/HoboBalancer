# v2 main unit, pin map and parts, 2026-10-25

A carrier board for off-the-shelf modules (decided 2026-10-25, replacing the OMGS3 board):

| Module | Part | Connection to the carrier |
|---|---|---|
| MCU | ESP32-S3 Feather: Unexpected Maker FeatherS3, or Adafruit ESP32-S3 Feather (5477) | female headers on U1; the 1S LiPo plugs into the Feather's own JST, which also charges it over USB-C |
| Accelerometer | SparkFun KX134 Qwiic (SEN-17589), ±64 g | Qwiic cable to the Feather's STEMMA QT plus one wire to J4 pin 5 (INT), or all five wires to J4. Bolted to the base plate |
| 12 V for the Banner | MT3608 boost module | input wired to J5, output to J6. Set the trim pot to 12 V with a meter before connecting the Banner |

The carrier itself holds the LM1815 magnetic-pickup input, the Banner input, the P-FET
switch that powers the boost module from the cell, the acquire button and the status LED.

## Signals by Feather position

The board uses only Feather positions that are plain GPIO on both Feathers, so either
plugs in. Firmware picks the GPIO numbers for the board it runs on.

| Signal | Feather position | FeatherS3 GPIO | Adafruit GPIO | Notes |
|---|---|---|---|---|
| MAG_TACH, LM1815 pin 12 | A0 | 17 | 18 | RTC GPIO on both, can wake the chip |
| OPT_TACH, Banner NPN | A1 | 18 | 17 | 10k pull-up to 3.3 V, 1k series |
| ACQUIRE button | A2 | 14 | 16 | 10k pull-up, 100 nF; RTC GPIO on both |
| STATUS LED | A3 | 12 | 15 | 1k series |
| BOOST_EN | A4 | 6 | 14 | high turns the boost module on; 100k holds it off at boot |
| ACCEL_INT, KX134 interrupt | A5 | 5 | 8 | data-ready, timestamped by MCPWM capture |
| ACCEL_SDA / SCL | SDA / SCL | 8 / 9 | 3 / 4 | the Feather's I2C, shared with its STEMMA QT port |
| VBAT | BAT | | | the cell; feeds the boost switch |
| 3.3 V, GND | 3V, GND | | | the Feather's regulator powers the LM1815, KX134 and pull-ups |

Open on purpose: AREF (FeatherS3 IO0, a strapping pin), the 16th pin (FeatherS3 LDO2
output), RST, EN, USB, and D5 to D13. Sources: Unexpected Maker FeatherS3 pinout card
(github.com/UnexpectedMaker/esp32s3) and Adafruit's arduino-esp32 variant
`adafruit_feather_esp32s3/pins_arduino.h`, both read 2026-10-25.

Board-specific notes:
- Adafruit: the STEMMA QT port's power is switched by GPIO 7. Drive it high if the KX134
  is on the Qwiic cable.
- FeatherS3: the horizontal STEMMA QT port is on IO8/IO9, the same bus as SDA/SCL.

## Parts on the carrier

| Block | Parts |
|---|---|
| Feather | U1 on two female headers (16 and 12 pin) |
| Boost switch | Q1 AO3400A, R16 1k, R18 100k; Q2 AO3401A high-side from VBAT, R17 100k gate pull-up; J5 pads to the module's IN+/IN-, J6 pads from OUT+/OUT- |
| MPU input | J3 pads, R9/R10 10k series, U4 LM1815, R11 100k / C8 1n C0G one-shot, R12 1.6M / C9 330n hold, R13 10k pull-up, C10 100n |
| Banner input | J2 pads (brown +12V, blue GND, white NPN), R14 10k pull-up to 3.3 V, R15 1k series |
| KX134 | J4 1x05 header: 3V3, GND, SDA, SCL, INT |
| UI | SW1 6 mm tact, R19 10k, C11 100n; LED1 0603, R20 1k |
| Mechanical | H1-H4 M3, 64 x 54 mm outline, Feather USB end at the top edge |

Passive values: resistors 10k, 100k, 1k, 1.6M; capacitors 100n, 1n C0G, 330n. Every
passive is 1206 except LED1 (0603). ICs: LM1815 SOIC-14, two SOT-23 FETs.

Generated by `BalancerMain/scripts/`: `build_main.py` (schematic), `verify_main.py`
(rebuilds the netlist from the file and checks every expected connection),
`build_pcb_main.py` (placed, unrouted board), `check_pcb_main.py` (pad nets, overlaps,
outline, nothing under the Feather) and `render_placement.py`. Run them in that order
after any change to the generators.

## Before ordering

- Open in KiCad and run ERC and DRC; route the board.
- Confirm the SparkFun KX134 board breaks out an interrupt pin and that its holes suit the plate.
- Check the female-header height clears everything on the carrier (only SMD parts sit near the Feather).
